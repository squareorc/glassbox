GlassBox: Privacy-Preserving LLM Framework

A verifiably explainable system for analyzing sensitive healthcare data with automatic PII redaction and evidence-based verification

Project Overview

GlassBox addresses two critical problems in LLM systems handling sensitive documents:

🔒
Privacy Risk: Automatic detection and redaction of PII before any data reaches the LLM, minimizing exposure of names, IDs, and identifying information.
✓
Verifiable Explanations: Independent verification mechanism that checks whether each LLM claim is actually supported by its cited evidence (planned).

Known Issue

ADDRESS detection: Presidio fragments addresses into separate NAME/LOCATION entities. With IoU ≥ 0.5 matching, fragments don't overlap enough with full ground-truth spans. Future work: merge adjacent entities with address-specific context.

Synthetic Dataset (250 Notes)

Generated with exact ground-truth PII annotations for rigorous evaluation:

  • 8 medical conditions: Essential hypertension, Type 2 diabetes, Major depressive disorder, COPD, Chronic kidney disease stage 3, Atrial fibrillation, Hyperlipidemia, Asthma
  • 834 PII entities with tracked character offsets (100% span accuracy verified)
  • Note formats: SOAP notes, discharge summaries, consultation notes
  • PII types: Names, PATIENT_ID (2 letters + 6 digits), DOB, phone, email, address

Realistic Dataset (2,500 Notes)

Scaled evaluation on complex EHR-style documentation:

  • 17,544 total PII entities across diverse formats
  • Multiple providers: Attending physicians, referring physicians, emergency contacts
  • Complex documentation: Progress notes with vitals, lab orders, ICD-10 codes
  • Format variations: Standard, parentheses, extensions, international phone formats

Project Contributions

GlassBox's core contribution is a working, evaluated integration of privacy-minimization and verifiable evidence-tracing into a single pipeline, with empirical analysis of the tradeoff between privacy protection, answer utility, and explanation faithfulness.

Key Design Decisions

  • Local LLM: Privacy guarantee extends to model-serving, not just preprocessing
  • Synthetic healthcare data: Enables exact ground-truth PII locations for rigorous evaluation without data-use approvals
  • Deterministic redaction: Entity detection + masking (formal privacy methods like differential privacy deferred to future work)
  • End-to-end audit trail: Every stage's output logged and inspectable
